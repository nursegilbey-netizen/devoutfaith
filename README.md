# DevoutFaith

| Project | What it is |
|---|---|
| [`scripture-foundations/`](scripture-foundations/) | Scripture Foundations: a Bible memorization and study app (KJV + BSB) for Android and the web. See its README for build and upload steps. |

Each push to `main` runs **Actions → Build Scripture Foundations**. The run produces the Android APK and a website bundle ready to upload to devoutfaith.com.
